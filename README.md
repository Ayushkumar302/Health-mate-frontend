# Health Mate Frontend

Health Mate is a comprehensive healthcare web application that allows users to seamlessly manage their medical appointments, view health data, and communicate with healthcare providers. The frontend is built using React, Vite, and Tailwind CSS.

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Create a `.env.local` file in the root directory based on the sample below.
4. Run `npm run dev` to start the development server.

## Sample Environment Variables

Create a `.env.local` file in the root directory and add the following variables:

```env
VITE_CLOUD_NAME=your_cloudinary_cloud_name
VITE_UPLOAD_PRESET=your_cloudinary_upload_preset
```
